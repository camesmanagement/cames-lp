# カウチソファー配置シミュレーション（マナー④ / グラシエーロⅡ）

実際のリビング写真をベースに、左側の壁（175cm）に背面を付けて新しいカウチソファーを置いた場合の完成イメージを、
写真から推定したカメラで 3D モデルを投影する方式（フォトモンタージュ）で作成したものです。
画像生成AIは使っていません。部屋の写真はそのまま背景として使い、青いソファーの領域だけを除去して差し替えています。

## Web ページの使い方

- `index.html` をブラウザで開く（Chrome / Edge / Safari）。右パネルの A〜D で切替。
- ホイールで拡大、ドラッグで移動、ダブルクリックでリセット。画像上をクリックすると床面座標（窓の壁から X cm／左の壁から Y cm）が出ます。
- 「配置の微調整」：窓側の壁との隙間・左の壁との隙間を変更すると、はみ出し量とソファーの描画・上面図が連動します。
- 「カメラ」：写真から推定した値（yaw/pitch/roll/f/X/Y/Z）を微調整できます。「部屋の基準線を表示」をONにすると、壁・天井・窓上端・エアコンの線が写真と合っているか確認できます。
- 「元の写真を重ねる」「元写真ワイプ」で青いソファーのある元写真と比較できます。
- PNG 書き出しはローカルサーバー（例 `python3 -m http.server`）で開いた場合のみ動作します（file:// 直開きはブラウザの制限で保存不可）。

## 配置条件（確認済み）

| 項目 | A/B マナー④ | C/D グラシエーロⅡ |
|---|---|---|
| ソファー背面 | 左側の壁（175cm）に沿わせる（隙間 2cm） | 同左 |
| カウチ | 奥の窓側（窓の壁に接する位置から、テレビ方向へ奥行150cm） | 同左 |
| 全幅 | 215cm（2P 142 ＋ 1Pカウチ 73） | 222cm（1.5P 122 ＋ シェーズロング 100） |
| 壁からのはみ出し | **40cm**（キッチン側＝写真手前） | **47cm**（キッチン側） |
| 奥行 | ソファ部 86.5 / カウチ部 150 | ソファ部 94 / カウチ部 150 |
| 高さ / 座面高 / 脚高 | 81 / 36.5 / 11 cm | 79 / 42 / 13 cm |

写真のカメラは壁の終端から約 2.6m キッチン側、左の壁の延長線上のほぼ真上（壁から約5cm）にあり、
ソファーの手前端（キッチン側）はカメラのすぐ前に来ます。そのため、はみ出した 40/47cm の部分は
画面左下へ向かって大きく伸び、座面の手前の角は画面下端の外に出ます。縮小はしていません（黄色の線が壁の終端 175cm、その手前にも背もたれが続いています）。

## カメラ推定（スケールの根拠と限界）

- 基準：壁 175cm、天井高 240cm（仮定）、エアコン幅 80cm（仮定）、窓上端・右壁の梁・ドア枠の直線（消失点）。
  最小二乗で当てはめ、残差 約9px（4000px幅）。推定結果：焦点距離 2873px、yaw 25.8°、pitch 3.4°下向き、roll −1.4°、位置 X=440cm（窓の壁から）/ Y=5cm（左の壁から）/ 高さ 156cm。
- 壁175cmはカメラからほぼ正面奥方向に伸びるため、写真だけでは奥行方向のスケール決定が弱く、天井高とエアコン幅の仮定に依存します。
  天井高が 240cm でない場合、実寸は数％ずれます。寸法入り間取り図があれば `assets/camera_fit.json` と `index.html` のカメラ欄で補正できます。
- 部屋の幅は約 316cm、窓の開口は約 261cm と推定されました（`renders/camera_calibration_check.jpg` 参照）。

## 既知の制約

- ソファーは公式寸法に合わせた簡略 3D モデルです（縫い目やクッションの膨らみなどの細部は再現していません）。
- 現在のローテーブル（100×50cm、写真から推定）は左端が壁から約137cmの位置にあり、カウチ奥行150cmと約13cm重なります。画像ではテーブルを現在位置のまま前景として残しているため、実際にはテーブルをテレビ側へ15cm以上ずらす必要があります。
- 照明は写真の天井LEDを想定した近似です。床・壁への影は推定で、実際の見え方と差があります。
