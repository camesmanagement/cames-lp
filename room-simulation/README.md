# リビング・ダイニング 実寸3Dシミュレーター（320×430cm）

部屋の指定寸法（横320cm × 奥行430cm、13.76㎡）と添付写真をもとに、three.js で部屋を実寸（1単位＝1cm）で再現し、
アルネ3人掛けソファ・ダイニングテーブル・チェア2脚・プレイマットを配置するシミュレーターです。
フォトリアルなレンダラーや画像生成AIは使っていません。リアルタイム3D描画のため、質感は近似ですが、寸法・配置・通路幅は実寸で計算しています。

## 使い方

- `index.html` をブラウザで開く（three.js 同梱、ダブルクリックで動作）。
- 右上「3D」「2D間取り図」で切替。2D間取り図は家具を動かすと寸法・通路幅が自動更新されます。
- カメラ：①玄関側→ベランダ ②ベランダ側→キッチン ③俯瞰 ④写真と同じアングル 上面（2D）。ドラッグ＝回転、ホイール＝ズーム、右ドラッグ＝移動。
- 家具：クリックで選択、床の上でドラッグ移動（上面ビューが操作しやすい）。矢印キー1cm移動（Shiftで10cm）、Rで90°回転。右パネルで中心座標・回転・幅×奥行を数値入力、壁寄せボタンあり。
- 「パターンA / B」でテーブル 120×75 / 130×80 を切替（標準配置にリセット）。
- 「この視点をPNG保存」「間取り図をSVG保存」で書き出し（file:// 直開きでも動作）。
- テレビ台のベランダ側からの距離（既定100cm）は右パネルで変更できます。

## 座標系と間取り（固定要素）

- 上側320cmの壁（y=0）：左にカウンターキッチン（開口 x25〜175、推定150cm、カウンター天板高100cm）、右に玄関側の室内ドア（x215〜290、幅75cm推定、右吊元・室内側に開く）。
- 下側320cmの壁（y=430）：右端にベランダ掃き出し窓172cm（x148〜320）、左側は壁148cm。窓上に梁・エアコン（写真より）。
- 左側430cmの壁（x=0）：テレビ台120×40cm、ベランダ側の角からテレビ台の近い端まで100cm（仮定・調整可）。50インチ級テレビ。
- 右側430cmの壁（x=320）：固定家具なし。写真の引き戸（窓側の壁175cmの先、y85〜255）を「推定」として表示（チェックで非表示）。
- 天井高240cm、床は写真のオーク系フローリング（板は320cm壁と平行）、壁は白系クロス。

左右の反転はしていません（上から見て、左＝テレビ、下＝ベランダ、上＝キッチン・玄関ドア）。

|---|---|---|
| ソファ右端 → ドア枠 | 16cm（ドアの軌跡に干渉なし） | 16cm |
| 玄関→ベランダ通路幅（右側・最小、ソファ右端〜右壁） | 121cm | 121cm |
| テーブル右端 → 右壁 | 156cm | 151cm |
| テーブル左端 → 左壁 | 45cm | 40cm |
| 椅子を引く余地（椅子の背→マット） | 40cm | 40cm |
| マット → 窓側の壁 | 16cm | 11cm |
| 窓(172cm)前の空き幅 | 172cm（マット右端が窓幅に20cm掛かるが床置きのため出入り可） | 同左 |

いずれも家具同士の重なり・部屋からのはみ出しはありません。数値はシミュレーター内で家具を動かすと再計算されます。

## 制約・注意

- カウンター開口・ドア幅・引き戸開口・天井高・梁は写真からの推定です。`tools/room_template.html` の `FIX` を修正して `build_room.py` を実行すると反映されます。
- 通路幅は家具の外接矩形から算出した最小値で、60cm未満を赤で警告します。椅子を引くスペースは40cm以上を目安にしています。
- 日光の入り方は窓（下側の壁）からの平行光で表現した近似です。方位は不明のため仮です。
